# Задачи

Одностраничное веб-приложение для учёта рабочих задач.

Поля задачи: **название**, **статус**, **ответственный(ые)**, **примечание**.

## Какие задачи решает программа

Программа закрывает повседневную потребность команды в учёте рабочих задач
и заменяет разрозненные заметки, таблицы и переписку единым реестром:

1. **Единое место для всех задач.** Все рабочие задачи собираются в одном
   списке, доступном из браузера на любом устройстве в сети. Не нужно
   держать задачи в голове, в чатах или в файлах - всё видно сразу.
2. **Контроль состояния работ.** Каждая задача проходит стадии: Новая,
   В работе, Выполнена, Отложена. В любой момент видно, что уже сделано,
   что в процессе, а что застряло.
3. **Фиксация ответственности.** Для каждой задачи указываются
   ответственные (можно несколько). Всегда понятно, к кому обращаться
   по конкретной задаче и кто за неё отвечает.
4. **Быстрый поиск и фильтрация.** Среди большого числа задач нужная
   находится за секунды: поиск по названию и ответственным, фильтр
   по статусу.
5. **Оперативное ведение.** Статус меняется прямо из списка, без
   перезагрузки страницы; задачи редактируются и удаляются в пару кликов.
6. **Конфиденциальность данных.** Данные хранятся локально в базе SQLite
   на своём сервере. Приложение не обращается к внешним сервисам -
   рабочие данные не покидают вашу инфраструктуру.
7. **Простота внедрения и поддержки.** Это одно небольшое приложение
   с минимумом зависимостей: разворачивается за несколько минут,
   автоматически поднимается как системный сервис и покрыто автотестами.

## Возможности

- Добавление задачи (форма сверху)
- Изменение статуса прямо из списка (выпадающий список в строке)
- Редактирование и удаление задач
- Фильтр по статусу и поиск по названию / ответственным
- Несколько ответственных через запятую (показываются тегами)
- Тёмная тема, без внешних API (HTMX подключён локально)

Статусы: Новая, В работе, Выполнена, Отложена.

## Стек

FastAPI + Jinja2 + HTMX + SQLite (sqlite3, без ORM).

## Развёртывание на Ubuntu одной командой

```bash
bash <(curl -s https://raw.githubusercontent.com/ArturShi/zadachi/main/install.sh)
```

Скрипт сам скачает код, создаст виртуальное окружение, установит
зависимости, зарегистрирует сервис автозапуска (systemd) и проверит,
что приложение отвечает. После установки откройте http://localhost:8010

Опции:

- `ZADACHI_PORT=8080` - установить на другой порт (по умолчанию 8010)
- `ZADACHI_NO_SYSTEMD=1` - только код и окружение, без сервиса автозапуска
  (для разработки или ручного запуска)

Пример с другим портом:

```bash
ZADACHI_PORT=8080 bash <(curl -s https://raw.githubusercontent.com/ArturShi/zadachi/main/install.sh)
```

Или развернуть из уже скачанного репозитория:

```bash
git clone https://github.com/ArturShi/zadachi.git && cd zadachi
bash install.sh
```

## Установка на Windows (установочный пакет)

Готовый установщик собирается автоматически в GitHub Actions и лежит на
странице **Releases**: https://github.com/ArturShi/zadachi/releases
(файл `Zadachi-Setup-1.0.0.exe`, там же портативная версия `Zadachi-portable-win64.zip`).

### Установка

1. Скачайте `Zadachi-Setup-1.0.0.exe` из Releases.
2. Запустите файл - **права администратора не нужны** (установка в профиль
   пользователя).
3. В мастере нажмите «Далее» → «Установить». При желании отметьте
   «Запускать при входе в Windows» (автозапуск) и ярлык на рабочем столе.

### Запуск и использование

- Запустите «Задачи» из меню Пуск (или с рабочего стола). Откроется окно
  сервера и браузер с адресом http://127.0.0.1:8010
- Пока приложение работает, окно сервера должно быть открыто. Для остановки
  закройте окно или нажмите Ctrl+C.
- Если порт 8010 занят, приложение само выберет следующий свободный (8011,
  8012, ...) и откроет браузер с фактическим адресом. Стартовый порт можно
  задать переменной окружения `ZADACHI_PORT`.

### Где хранятся данные

- База данных: `%LOCALAPPDATA%\Zadachi\tasks.db`
  (например, `C:\Users\Имя\AppData\Local\Zadachi\tasks.db`).
- При удалении программы данные **не удаляются**. Резервная копия - это
  обычное копирование файла `tasks.db`.

### Полезно знать

- Приложение доступно только с этого компьютера (слушает `127.0.0.1`).
  Чтобы работать с других устройств по сети - разверните серверную версию
  (раздел «Развёртывание на Ubuntu»).
- Обновление: запустите новый установщик поверх старого - все данные
  сохранятся.
- Удаление: «Параметры → Приложения → Задачи → Удалить».
- Сборка установщика из исходников: см. `.github/workflows/windows-build.yml`
  (PyInstaller + Inno Setup, `installer/zadachi.iss`).

## Запуск

```bash
# окружение (один раз)
python3 -m venv ~/venvs/zadachi
~/venvs/zadachi/bin/pip install -r requirements.txt

# разработка
cd ~/work/Задачи
~/venvs/zadachi/bin/uvicorn app.main:app --host 0.0.0.0 --port 8010
```

Открыть http://localhost:8010

## Продакшен (systemd)

Пример сервиса `zadachi.service` (автозапуск при загрузке, автоперезапуск
при падении, 2 воркера):

```ini
[Unit]
Description=Zadachi - веб-приложение учёта рабочих задач
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=<ваш-пользователь>
WorkingDirectory=<путь-к-проекту>
ExecStart=<путь-к-venv>/bin/uvicorn app.main:app --host 0.0.0.0 --port 8010 --workers 2
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now zadachi
sudo systemctl status zadachi   # состояние
sudo journalctl -u zadachi -f   # логи
```

База данных создаётся автоматически в `~/.local/share/zadachi/tasks.db`
(локально, вне сетевого диска - надёжнее). Для тестов путь задаётся
переменной `ZADACHI_DB`.
